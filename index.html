About Me

Who I Am

Pentesting

I'm a third-year Computer Science student at Cairo University currently building my foundation in Cybersecurity, with a current focus on Penetration Testing and Vulnerability Assessment. I'm interested in understanding how systems and applications can be attacked, assessed, and ultimately secured.

My programming background in Java, Python, and C++ gives me a strong technical foundation for security. I'm now applying that foundation to offensive security labs, learning how to enumerate targets, identify vulnerabilities, understand exploitation paths, and document security findings.

At this stage, my main learning path is penetration testing and vulnerability assessment. I'm developing practical experience with web and system security testing through controlled labs and hands-on exercises, including vulnerability identification and exploitation.

My long-term goal is to move toward Application Security, where I can combine offensive security experience with my software development background to help find and prevent vulnerabilities earlier in the development lifecycle. For now, I'm focused on building the practical penetration-testing foundation that will get me there.
